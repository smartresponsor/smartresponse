# Interfacing provider admin density hardening

This wave tightens the neutral provider design baseline so active Interfacing pages more closely match a compact straight-line admin/workbench visual density.

Rules:

- no external admin bundle dependency in Interfacing;
- no external admin bundle naming in runtime tokens;
- use a native CSS/token layer consumed by Twig, Ant Design/ProComponents and PrimeReact providers;
- controls use 13px font, 32px height, straight corners, flat borders and restrained focus ring;
- main content headings use restrained 500 weight instead of marketing-heavy headings;
- cards/panels are flat bordered surfaces, not rounded marketing cards.
