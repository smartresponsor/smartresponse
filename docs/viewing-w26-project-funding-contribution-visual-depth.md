# Viewing W26 — Project / Funding / Contribution visual depth

This wave deepens the Interfacing template layer for project-commerce surfaces.

## Scope

Touched templates are limited to:

- `Interfacing/template/project/*`
- `Interfacing/template/partial/*`
- `Interfacing/template/project/_contract.yaml`

No controllers, routes, API declarations, runtime services, JavaScript frameworks, Vue, React, or Vite configuration are changed.

## Canon

Project templates are noun-surface templates. They are not component-owner folders. Producer components own the payload. Viewing owns response selection. Interfacing owns visual composition.
